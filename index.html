Windows API Manual Alpha Compositing

True Manual Alpha Compositing using Windows UpdateLayeredWindow API

How it works:

  • WGPU renders to intermediate texture (not directly to window)
  • Texture data is read back to CPU memory
  • Windows UpdateLayeredWindow API composites with proper alpha
  • Premultiplied alpha ensures correct transparency blending
  • CompositeAlphaMode::Opaque hardware limitation bypassed

You should see properly transparent colored circles floating over the desktop. This method works even when hardware only supports opaque compositing.
